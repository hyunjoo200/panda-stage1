# 중국어 탐험대 STAGE 01 · 대나무 언덕의 비밀

초등 5·6학년 1차시 성조(mā·má·mǎ·mà) 복습용 횡스크롤 게임입니다.

## GitHub에 올릴 파일
저장소 맨 위(최상위)에 아래를 그대로 올립니다.

- index.html — 화면 틀
- style.css — 꾸미기
- game.js — 게임 프로그램 (고치지 않아도 됨)
- game-data.js — **선생님이 고치는 파일** (문제, 점수, 별·버섯 위치, 음성 설정)
- audio/ — 검수된 녹음 MP3를 넣는 폴더 (이름은 audio/README.txt 참고)

## 게임 규칙
- ←→ / A·D 달리기, ↑ / W / 스페이스 점프, 휴대폰은 화면 버튼
- 별 +10 (별 점수), 통통 버섯과 부딪히면 별 점수 -10 (학습 점수는 줄지 않음), 위에서 밟으면 3초 동안 어지러워함
- 소리의 종 5개: 처음에 맞히면 100, 다시 맞히면 60 (학습 점수)
- 보너스 상자(구름 계단 위): 50 / 30
- 종 5개를 모두 울리면 언덕 끝의 문이 열리고 STAGE CLEAR, STAGE 02 문은 잠겨 있음
- 낭떠러지와 게임 오버 없음, 15초 동안 종을 못 찾으면 화살표 안내

## 알아 둘 점
- 결과는 아직 학생 기기에만 저장됩니다. 교사용 화면 연결은 다음 단계입니다.
- 녹음 파일이 없으면 온라인 자동 음성 → 기기 음성 순서로 재생되며, 화면에 '임시 음성(성조 검수 전)'이 표시됩니다.
