# 중국어 탐험대 STAGE 01 · 대나무 언덕의 비밀 (1차시 수정본 반영)

초등 5·6학년 1차시 복습용 횡스크롤 게임입니다. 수정된 1차시 PPT 내용을 세 구역으로 나누어 담았습니다.

| 구역 | 내용 (PPT 쪽수) | 문제 |
| --- | --- | --- |
| 1. 성조 숲 | mā má mǎ mà, 채팅 성조 번호 (6~18쪽) | 5개 |
| 2. 소리 마을 | 听·说 그림 발음, 妈妈骂马와 경성 (12~22쪽) | 5개 + 보너스 |
| 3. 인사 다리 | 你好, 你们好, 老师好, 同学们好, 我很好, 好 한자 (25~33쪽) | 4개 + 마지막 인사 |

## GitHub에 올릴 파일 (저장소 맨 위)
- index.html, style.css, game.js — 게임 (고치지 않아도 됨)
- game-data.js — **선생님이 고치는 파일** (구역 수, 문제, 점수, 음성)
- sound-check.html — 휴대폰 소리 점검
- audio-list.html — 음성 파일 목록과 저장 방법
- audio/ — 녹음 MP3를 넣는 폴더

## 수업 시간에 맞추기
수업 계획의 게임 시간은 5분입니다. game-data.js 맨 위의 `playZones`를 바꾸세요.
- `playZones: 1` 성조 숲만 (약 3~4분) — 수업 중 5분 복습용
- `playZones: 3` 전체 (약 9~11분) — 수업 뒤 과제나 다음 시간 복습용

## 점수
- 학습 점수: 처음 100, 다시 맞히면 60 (보너스 50/30)
- 별 점수: 별 +10, 통통 버섯과 부딪히면 -10 (학습 점수는 줄지 않음)
- 결과는 아직 학생 기기에만 저장됩니다. 교사용 화면 연결은 다음 단계입니다.
